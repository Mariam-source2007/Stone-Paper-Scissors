Rock Paper Scissors

A simple Rock Paper Scissors game implemented in C++.

About

This project is a console-based game where the player competes against the computer.

The game follows the classic rules:

- 🪨 Rock beats Scissors
- 📄 Paper beats Rock
- ✂️ Scissors beats Paper

Features

- Player vs Computer
- Random computer choices
- Displays the result of each round
- Simple console interface

Technologies

- C++
- Standard Library
- Random number generation

Project Purpose

This project was created as a practice project to improve my C++ programming skills and work with concepts such as:

- Functions
- Conditional statements
- Loops
- Random numbers
- User input and output
